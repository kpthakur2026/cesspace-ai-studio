# CES AI Studio SaaS — Stages

1. Upstream qualification and license/SBOM audit. Choose a UI/runtime after compatibility test.
2. Prompt-to-site: DeepSeek gateway, coding agent, preview and follow-up edits.
3. Central CesSpace login and organization/project tenant boundaries; authorization and entitlements distinct.
4. Premium UX: visual editing, responsive preview, checkpoints, history and rollback.
5. Design/QA agents: screenshot critique, browser tests, debugging and bounded automatic repairs.
6. Commercial SaaS: payment verification, credit ledger, quotas, plans, custom domain and publishing.
7. Production security: isolation tests, abuse controls, backup/restore, observability, spend caps, explicit release gate.

Security boundary: public repository must never hold production secrets or private CES source. Generated website code is untrusted.
No production or account privilege activation is authorized by this roadmap.
